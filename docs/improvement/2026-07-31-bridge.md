## Applied (safe-fix, on branch `improve/bridge-errprefix`)

## Applied (security cluster #9/#10/#11, branch `feat/attachment-hardening`)

- **#9 DNS rebinding** — `pinnedClient` wraps the caller's client (a copy; the original is untouched), hoists the redirect re-validation out of `fetchOne`, and installs a dialer that resolves the host once, refuses anything not publicly routable, and connects to the exact address it checked. An allowlist entry that is already an IP literal is dialled as given — there is no name to rebind.
- **#10 `file://` passthrough** — `StagingRoot()` is now the one tree an attachment may live in, and `stagedPath` resolves symlinks on both sides before checking containment. The terminal `/attach` copies the named file into the staging tree instead of pointing at it, so the invariant the core checks is one a gateway actually satisfies.
- **#11 modes** — the staging dir is created 0700 and downloads land 0600, since the tree sits in a world-writable temp dir.

## Feature ideas (grounded in existing code)

1. **Per-turn/session cost & token guardrail** that auto-interrupts runaway turns — reuses the accumulated `cost/outTok/...` telemetry + `turnController.interrupt()`. _(medium)_
2. **Preserve streamed partial output on interrupt** — buffer rendered chunks, emit as final reply instead of replacing with `⚠️ context canceled`. _(medium)_
3. **Support document attachments (PDF/text)** — the SSRF/size/count machinery is content-type agnostic; only `isImage` gates it. _(medium)_
4. **Validate delegation/route trailers against the live roster** — catch hallucinated agent names where the bridge already holds output + roster. _(medium)_
5. **Emit a skill-activation status event** — `eng.Detect(out)` already knows which skill fired; surface it so gateways can show "used skill: X". _(small)_
6. **Attachment directory GC** — age/count-based sweep of the per-session temp dir at turn start; today staged images accumulate for the host's life. _(small)_
